# 📅 جدولي الدراسي — Study Schedule

موقع ويب تفاعلي لعرض وإدارة الجدول الدراسي الأسبوعي، مبني بالكامل بـ **HTML, CSS, JavaScript** بدون أي framework أو مكتبات خارجية، ومنشور مباشرة عبر GitHub Pages.

### 🔗 جرّبه مباشرة
**https://moh33albolihi-create.github.io/study-schedule/**

---

## ✨ المميزات

- **جدول أسبوعي كامل** — تصفح 20 أسبوع دراسي بالتقويم الهجري والميلادي مع بعض
- **قابل للتخصيص بالكامل** — كل زائر يبني جدوله الخاص (محاضرات، شعب، أوقات) من لوحة تحكم بسيطة
- **الاختبارات النهائية** — تُعرض تلقائيًا في يومها بكرت مميز فيه الوقت والقاعة والمحاضر
- **الواجبات والمشاريع** — عدّاد تنازلي لآخر موعد تسليم + إضافة مباشرة لتقويم Google أو تحميل ملف `.ics` لأي تقويم آخر
- **ملاحظات يومية** — تدوين ملاحظات خاصة لكل يوم تُحفظ تلقائيًا
- **مؤشر "جارية الآن"** — يوضح أي محاضرة تكون قائمة فعليًا وقت فتح الموقع
- **تصميم مظلم متجاوب** — يعمل بسلاسة على الجوال والحاسوب

## 🗂️ كيف تُحفظ البيانات؟

كل البيانات (المحاضرات، الاختبارات، الواجبات، الملاحظات) تُحفظ محليًا في متصفح كل زائر (`localStorage`) — بدون تسجيل دخول أو خادم خلفي. يعني جدولك خاص فيك، وما يشوفه أحد غيرك.
